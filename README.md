# Azure Cosmos DB Projects

This repository is a collection of enterprise-grade projects demonstrating advanced Azure Cosmos DB architectural patterns. It serves as a comprehensive resource for understanding how Cosmos DB can be leveraged in real-world scenarios.

## 🗂️ Projects

### [Real-Time Healthcare Claims Processing System](./HealthcareClaims/README.md)
A high-throughput application demonstrating the ingestion and real-time processing of healthcare claims. It uses C# .NET 8, Angular 18+, the Cosmos DB Change Feed, and Azure SignalR Service to push live updates to a dashboard.
